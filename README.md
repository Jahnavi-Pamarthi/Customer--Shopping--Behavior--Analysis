# Customer Shopping Behaviour Analysis 
## Project Overview
This project analyzes customer shopping behavior using Python, SQL, and Power BI. The objective is to clean raw customer transaction data, analyze sales trends, and create interactive dashboards for business insights. 
## Tools & Technologies - Python (Pandas, NumPy, VS Code) - SQL (MySQL), - Power BI - Excel 
## Workflow1. Data Cleaning using Python, 2). SQL analysis, 3). Power BI dashboard development, 4). Business insights & reporting. 
## Key Features- clean and preprocessed 3,900+ customer transaction records, performed customer segmentation, analyzed product performance and sales trends, built interactive Power BI dashboards with KPIs and visualizations.
## Files Included: Python scripts, SQL queries, Power BI dashboard (.pbix), Excel dataset, project report.
